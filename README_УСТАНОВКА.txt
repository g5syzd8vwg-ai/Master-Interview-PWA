RC14: исправление неверных показателей Question Bank

1. Сделайте Encrypted Complete Backup в PWA.
2. На GitHub откройте g5syzd8vwg-ai/Master-Interview-PWA, файл index.html в корне.
3. Замените содержимое index.html на файл из этого ZIP (или исправьте ?v=RC10 на ?v=RC14 в двух ссылках app.js и styles.css).
4. Commit changes.
5. После публикации GitHub Pages полностью закройте PWA и откройте в браузере заново; выполните принудительное обновление (Mac Cmd+Shift+R).
6. Проверьте Question Bank: 658 Approved / 609 Active / 49 Inactive.

НЕ удаляйте IndexedDB, данные сайта, PIN или интервью.
Если показатели не исправятся, проверьте в View Source строки app.js?v=RC14 и styles.css?v=RC14, а затем скачайте Question Bank Audit и сообщите approvedCount, activeCount, inactiveCount.
